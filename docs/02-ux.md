# Print Vira Meme — UX (Etapa 2)

**Status:** v1.0 — aprovada em 2026-09-05 (10 decisões da seção 7 aceitas) · **Depende de:** [01-product-spec.md](01-product-spec.md) (v1.0 aprovada)

---

## 0. Princípios de UX (o que decide qualquer dúvida)

1. **Compartilhar é o fim de toda jornada.** Cada tela existe para chegar mais rápido ao botão "Compartilhar".
2. **O usuário escolhe, não edita.** Tudo já vem preenchido; editar é opcional.
3. **Nada bloqueia a criação.** Paywall e anúncios acontecem *depois* do valor, nunca no caminho para ele.
4. **Uma ação primária por tela.** Sempre um botão grande e óbvio; o resto é secundário.
5. **A foto do usuário é a estrela.** Aparece o mais cedo possível — inclusive nos cards de template.

```
   │   /    │                                            │
   └────────┘                                            ▼
        ▲                                     ┌───────────────────────┐
        │                                     │        /editor        │◄──► [sheet texto]
        │                                     │  textos, fonte, foto  │◄──► [/pro paywall]
        │                                     └──────────┬────────────┘

        └─────────────────────────────────────┤                       │

                                                         ▼
                                                     /templates (mesma foto)
```

| Rota | Tipo | Conteúdo |
|---|---|---|
| `/` | tela | Home |
| `/templates` | tela | Catálogo de presets (com filtro de categoria) |
| `/editor` | tela | Editor do meme |
| `/result` | tela | Resultado |
| `/pro` | modal (tela cheia) | Paywall |
| `/settings` | tela | Configurações |

| `[sheet texto]` | bottom sheet | Edição de um slot de texto + sugestões |

**Botão voltar (hardware/gesto):** Result → Editor (mantém textos) · Editor → Templates (mantém foto) · Templates → Home · sheets e paywall fecham. Nenhum "tem certeza?" — refazer um meme custa 20 segundos.

## 2. Estado da criação (o mínimo para a UX fazer sentido)

```
creation
  imageUri            foto redimensionada (máx. 1600px) no cache do app
  imageThumbUri       cópia pequena (~480px) para os cards de template
  presetId, layoutId  template escolhido
  values              { slotId: texto }        — textos atuais
  imageTransform      { scale, offsetX, offsetY } — enquadramento da foto no slot
  style               { fontId, caps, color?, outline? }
  lastExport          { uri, quality, hasBrand } — arquivo gerado

entitlements          { isPro, packIds[] }
counters              { exports, shares, exportsSinceAd, lastAdAt, shareMilestoneShown }
```

A criação aceita **foto e preset em qualquer ordem**; o editor só abre quando tem os dois. Estado vive na sessão (não persiste se o app for morto — a foto está no cache e o meme leva 20s).

**Objetivo:** levar ao "Criar meme" em 1 toque e mostrar, sem esforço, que "aqui eu faço memes".

```
│                              │
│ 🔥 Populares          ver ›  │
│ ┌────┐ ┌────┐ ┌────┐         │
│ │    │ │    │ │PRO │  →      │  ← carrossel horizontal
│ └────┘ └────┘ └────┘         │
│                              │

│ ┌────┐ ┌────┐ ┌────┐  →      │
```

**Componentes:** header (logo, pill PRO, engrenagem) · botão-herói "Criar meme" · chips de categoria · carrossel "Populares" (presets com flag `popular`, curadoria manual no MVP) · carrossel "Novidades" (presets adicionados nos últimos 30 dias; some se vazio) · card PRO discreto.

**Ações:** Criar meme → `[sheet foto]` · chip → `/templates?category=` · "ver ›" → `/templates?filter=popular|new` · card → `/templates` posicionado no preset **ou**, se o usuário já tem foto na sessão, direto `/editor` · PRO → `/pro` · ⚙ → `/settings`.

**Free:** pill "PRO" no header e card PRO no rodapé. Cards de preset premium com badge.
**PRO:** pill vira "✓ PRO" (sem ação além de abrir status em `/settings`); card PRO do rodapé some.

### 3.2 Seleção de imagem (`[sheet foto]`)

**Objetivo:** pegar a foto com o mínimo de decisões e deixar a promessa de privacidade explícita no único lugar em que ela importa.

```
┌──────────────────────────────┐
│           ────               │
│  De onde vem a foto?         │
│ ┌────────────┐ ┌───────────┐ │
│ │ 🖼 Galeria │ │ 📷 Câmera │ │
│ └────────────┘ └───────────┘ │
│ 🔒 Suas fotos ficam no seu   │
│    celular. Nada é enviado.  │
└──────────────────────────────┘
```

**Componentes:** dois botões grandes · linha de privacidade (sempre visível, é barata).

**Ações:** Galeria → seletor de fotos do sistema (Android 13+: Photo Picker, sem permissão; anteriores: pede permissão de leitura) · Câmera → câmera do sistema via `expo-image-picker` (pede permissão) · arrastar/voltar fecha.

**Ao escolher:** a foto é copiada para o cache, redimensionada (máx. 1600px) e gerada a miniatura; sheet fecha; segue para `/templates` (ou `/editor` se o preset já estava escolhido).

**Estados:** padrão · processando (spinner no botão, 100–400ms) · permissão negada (texto inline: "Sem acesso à galeria. Você pode liberar em Configurações." + botão "Abrir configurações") · câmera indisponível (botão desabilitado com legenda) · erro ao abrir a imagem ("Não consegui abrir essa imagem. Tenta outra?").

**Free = PRO.** Sem diferença.

### 3.3 Templates (`/templates`)

**Objetivo:** o momento "uau": o usuário vê a própria foto em vários memes ao mesmo tempo e só precisa escolher.

```
┌──────────────────────────────┐
│ ‹  Escolha o template   [📷] │  ← miniatura da foto; toque = trocar
│ [Todos][🔥][✨][😂][💼][❤️]… │  ← chips; a categoria vinda da Home já vem selecionada
│ ┌───────────┐ ┌───────────┐  │
│ │  preview  │ │  preview  │  │
│ │  com a    │ │       PRO │  │  ← preview ao vivo do layout com a foto do usuário
│ │  sua foto │ │           │  │
│ │ Nome      │ │ Nome      │  │
│ └───────────┘ └───────────┘  │
│ ┌───────────┐ ┌───────────┐  │
│ │           │ │           │  │
│ …            (grade 2 col.)  │
└──────────────────────────────┘
```

**Componentes:** header com miniatura da foto (ou "Sem foto" se veio pela Home sem foto) · chips de filtro (Todos, 🔥 Populares, ✨ Novos, 12 categorias) · grade de cards 2 colunas · card = preview + nome + badge PRO.

**Preview dos cards:** quando há foto na sessão, cada card renderiza o layout com **a foto do usuário** (miniatura de 480px, lista virtualizada, canvas em escala). Sem foto, usa uma foto-exemplo interna (ilustração própria). Isso é o principal argumento de "quero ver mais um".

**Ordenação dentro de um filtro:** campo `order` curado; regra editorial: pelo menos 4 dos 6 primeiros cards são free.

**Ações:** chip → filtra (mantém posição de scroll no topo) · card → se há foto, `/editor`; se não, `[sheet foto]` e depois `/editor` · miniatura → `[sheet foto]` (troca a foto, mantém filtro) · voltar → Home.

**Estados:** padrão com foto · padrão sem foto (foto-exemplo) · categoria vazia — não existe no MVP (catálogo garante ≥ 3 por categoria; presets aparecem em categorias secundárias por tag) · carregando previews (placeholders neutros por card enquanto a imagem decodifica).

**Free:** cards premium mostram badge "PRO"; **toque abre o editor normalmente** (experimenta antes — o bloqueio só acontece em "Gerar").
**PRO:** sem badges.

### 3.4 Editor (`/editor`)

**Objetivo:** confirmar ou ajustar o meme que já está pronto — e sair em um toque.

```
┌──────────────────────────────┐
│ ‹  Notícia Urgente   [ PRO ] │  ← pill só se o preset é premium e o usuário é Free
│ ┌──────────────────────────┐ │
│ │      PREVIEW DO MEME     │ │
│ │  toque no texto = edita  │ │
│ │  pinça/arrasta = ajusta  │ │
│ │  a foto no espaço        │ │
│ │               [🔄 foto]  │ │
│ └──────────────────────────┘ │
│ Textos                       │
│ ┌ Título ──────────────────┐ │
│ │ Brasileiro promete…    ✎ │ │  ← toque abre [sheet texto]
│ └──────────────────────────┘ │
│ ┌ Descrição ───────────────┐ │
│ │ Fontes confirmam que…  ✎ │ │
│ └──────────────────────────┘ │
│ Fonte  [Aa][Aa][Aa][🔒Aa][🔒Aa]│
│ Estilo [AA] [🔒 cor] [🔒 ⊞]  │
│ ┌──────────────────────────┐ │
│ │      ✨ GERAR MEME       │ │  ← fixo no rodapé
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

**Componentes:** header (nome do preset, pill PRO quando aplicável) · canvas de preview (largura total, proporção do layout, máx. ~55% da altura) · botão "Trocar foto" sobre o canvas · lista de slots de texto (um card por slot, na ordem do layout, com rótulo e prévia) · linha de fontes (3 free + 4 PRO com cadeado) · linha de estilo: CAPS (free), cor e contorno (PRO) · CTA fixo "Gerar meme".

**Interações no canvas:**
- Toque num texto → abre `[sheet texto]` daquele slot.
- Pinça e arraste **dentro do slot de imagem** → zoom/pan da foto (essencial: prints são altos e os slots costumam ser largos). Limites: a foto nunca deixa área vazia; zoom máx. 3x. Um toque duplo volta ao enquadramento inicial.
- PRO: arrastar um texto reposiciona (com guias de centro e "snap"); os demais elementos não se movem.

**Ações:** slot → `[sheet texto]` · fonte → aplica ao vivo; cadeado → `/pro` (gatilho `premium_font`) · CAPS → aplica ao vivo · cor/contorno (PRO) → seletor inline com 6 cores e liga/desliga · Trocar foto → `[sheet foto]` (mantém textos e estilo) · voltar → `/templates` (mantém tudo; ao escolher outro preset, textos migram para slots do mesmo tipo, o resto usa o padrão do novo preset) · **Gerar meme** → exporta em tela (0,3–1,5s com botão em estado "Gerando…") → `/result`.

**Regras de texto:** cada slot tem `maxChars` e `maxLines`; o renderizador reduz a fonte até um mínimo (`autoFit`) antes de truncar. Contador aparece a partir de 80% do limite.

**Estados:** padrão · gerando (CTA em progresso, tela bloqueada a toques por ≤ 2s) · falha na exportação ("Deu ruim ao gerar. Tentar de novo?" + botão; nada se perde) · preset premium + Free (pill PRO no header; CTA vira **"Desbloquear PRO e gerar"**) · foto ausente (não acontece: rota exige foto; se o arquivo de cache sumiu, volta ao `[sheet foto]` com aviso).

**Free:** edita textos, sugestões, 3 fontes, CAPS, zoom/pan da foto, trocar foto. Preset premium: pode montar, mas "Gerar" abre o paywall (`premium_template`); ao comprar, a exportação continua sozinha.
**PRO:** tudo do Free + 4 fontes, cor e contorno, arrastar textos, texto extra ("+ Texto" adiciona um slot livre), sem pill, sem marca no preview.

#### 3.4.1 Sheet de texto (`[sheet texto]`)

```
┌──────────────────────────────┐
│           ────               │
│ Título                 12/60 │
│ ┌──────────────────────────┐ │
│ │ Brasileiro promete…      │ │  ← autofoco, teclado aberto
│ └──────────────────────────┘ │
│ Sugestões               🎲   │
│ [Brasileiro promete começar…]│
│ [Homem afirma que vai econo…]│
│ [Especialistas confirmam…]   │
│ [Usuário entra no WhatsApp…] │
│                    [ Pronto ]│
└──────────────────────────────┘
```

**Componentes:** rótulo do slot + contador · campo (multilinha ou linha única conforme o slot) · lista de sugestões filtradas por **tipo do slot + categoria do preset** (depois as demais categorias) · 🎲 sorteia uma sugestão · "Pronto".

**Comportamento:** o canvas atrás atualiza **ao vivo** enquanto digita; tocar numa sugestão substitui o texto (não concatena); "Pronto", arrastar para baixo ou voltar fecham mantendo o texto; campo vazio → o slot mostra o placeholder do layout em cinza no editor e **é omitido na exportação** (permite tirar o subtítulo, por exemplo).

**Free = PRO.** As sugestões são as mesmas.

#### 3.4.2 Enquadramento da foto

Gestos direto no preview (sem modo "cortar"): pinça (zoom), arraste (pan), toque duplo (reset). Alternativa por botão sobre o canvas: **"Preencher / Encaixar"** — *Encaixar* mostra a foto inteira com fundo desfocado da própria foto (bom para prints inteiros de conversa). Free e PRO iguais.

### 3.5 Resultado (`/result`)

**Objetivo:** compartilhar. O arquivo já existe quando a tela abre; "Compartilhar" não espera nada.

```
┌──────────────────────────────┐
│ ‹  Ficou assim 🔥            │
│ ┌──────────────────────────┐ │
│ │                          │ │
│ │       MEME FINAL         │ │  ← imagem do arquivo exportado (o que vê = o que manda)
│ │                          │ │
│ │       (marca no Free)    │ │
│ └──────────────────────────┘ │
│  Tirar a marca d'água · PRO  │  ← só Free; texto pequeno
│ ┌──────────────────────────┐ │
│ │     📤 COMPARTILHAR      │ │
│ └──────────────────────────┘ │
│ [ 💾 Salvar ] [ 🔁 Outro template ] │
│        Criar outro meme      │  ← link discreto
└──────────────────────────────┘
```

**Componentes:** meme em tamanho grande (exibe o arquivo exportado, não o canvas) · link "Tirar a marca d'água · PRO" (Free) · CTA "Compartilhar" · botões secundários "Salvar" e "Outro template" · link "Criar outro meme".

**Ações:**
- **Compartilhar** → share sheet nativa do Android com o arquivo (evento `meme_shared`). Ao voltar, a tela permanece; se foi o 3º compartilhamento da vida do usuário e ele é Free → `[sheet PRO leve]` uma única vez.
- **Salvar** → grava na galeria (álbum "Print Vira Meme"); toast "Salvo na galeria ✓"; botão vira "Salvo ✓" (idempotente).
- **Outro template** → `/templates` com a mesma foto e os mesmos textos (migram por tipo de slot). **Sem anúncio.**
- **Criar outro meme** → limpa a criação → `[sheet foto]` na Home. **Passa pelo AdGate** (seção 4.1).
- Voltar → `/editor` (para ajustar). Voltar de novo → templates, etc.
- Tirar a marca → `/pro` (gatilho `remove_watermark`); ao comprar, **re-exporta automaticamente sem marca** e volta para esta tela.

**Estados:** padrão · salvando (spinner no botão) · salvo · permissão de galeria negada ("Sem acesso à galeria para salvar. Compartilhar funciona mesmo assim." + "Abrir configurações") · sem app para compartilhar (raro; mostra "Salvar" em destaque) · arquivo sumiu do cache (re-exporta em silêncio ao abrir a tela).

**Free:** marca visível no meme; link "Tirar a marca"; qualidade padrão (JPEG 1080px); `[sheet PRO leve]` no 3º compartilhamento; AdGate em "Criar outro".
**PRO:** sem marca; selo pequeno "HD ✓" abaixo do meme; sem link; sem anúncios; sem sheet.

**Ações:** comprar → fluxo do Google Play → sucesso: fecha, toast "Bem-vindo ao PRO 🎉", e **a ação que originou o gatilho continua sozinha** (gera o meme, re-exporta sem marca, aplica a fonte) · restaurar → consulta a Play → "Compra restaurada ✓" ou "Nenhuma compra encontrada nesta conta Google" · fechar → volta ao ponto anterior sem alterar nada.

O Google Play precisa de internet para a compra.") · já é PRO (a tela não abre; se aberta por deep link, mostra "Você já é PRO ✓").

**Free:** como acima. **PRO:** inacessível (entradas viram "✓ PRO").

#### 3.6.1 Sheet PRO leve (`[sheet PRO leve]`)

Bottom sheet de uma linha + dois botões: texto do gatilho (`ad_close` ou `share_milestone`), **"Ver o PRO"** → `/pro`, **"Agora não"** fecha. Nunca reaparece pelo mesmo gatilho (`share_milestone` é único por vida; `ad_close` no máximo 1 a cada 5 anúncios).

### 3.7 Configurações (`/settings`)

**Objetivo:** cumprir o que a Play exige (política, restaurar) e abrigar duas ações úteis, sem virar um menu.

**Itens (lista simples):**
1. Status: "Conheça o PRO ›" (Free) / "✓ Você é PRO" (PRO)
2. Restaurar compra
3. Compartilhar o app (share sheet com o link da Play — ação viral barata)
4. Avaliar na Play
5. Como suas fotos são tratadas (texto curto de 4 linhas: cache local, nada enviado, apagado automaticamente)
6. Política de privacidade (abre no navegador)
7. Limpar cache de imagens
8. Versão

**Estados:** restaurando (spinner) · resultado do restore (toast). **Free/PRO:** apenas o item 1 muda.

---

### 3.8 Entrada por "Compartilhar → Print Vira Meme"

Não é tela; é comportamento.

- **App fechado:** abre direto em `/templates` com a foto já processada (Home não aparece). Evento `app_open(entry=share_intent)`.
- **App aberto no meio de algo:** a nova foto substitui a criação atual e vai para `/templates`. Sem confirmação.
- **Várias imagens compartilhadas:** usa a primeira.
- **Conteúdo não-imagem (texto, link):** o app abre na Home com toast "Compartilhe uma imagem para virar meme".
- **Falha ao ler o arquivo:** Home + `[sheet foto]` com a mensagem de erro padrão.

## 4. Fluxos transversais

### 4.1 Anúncios — AdGate

Um único ponto de decisão, chamado nas transições **Resultado → "Criar outro meme"** e **Resultado → Home (voltar)**. Nunca em "Outro template", "Compartilhar", "Salvar", editor ou retorno da share sheet.

Mostra o interstitial **somente se todas** valem: não é PRO · `exports ≥ 2` · `exportsSinceAd ≥ 3` (o primeiro anúncio da vida é na 2ª exportação) · `agora − lastAdAt ≥ 3 min` · anúncio pré-carregado. Se o anúncio não estiver carregado, **segue sem anúncio** — nunca espera. Ao fechar: a cada 5 anúncios, `[sheet PRO leve]` (`ad_close`). Pré-carrega o próximo ao abrir o app e após cada exibição.

### 4.2 Gatilhos de paywall

| Gatilho | Onde | Formato | Ao comprar, continua com… |
|---|---|---|---|
| `premium_template` | Editor → Gerar com preset PRO | paywall | exportação |
| `premium_font` / `premium_style` | Editor → chip com cadeado | paywall | aplicação da fonte/estilo |
| `remove_watermark` | Resultado → link | paywall | re-exportação sem marca |
| `share_milestone` | Resultado, após o 3º compartilhamento | sheet leve → paywall | — |
| `ad_close` | fechamento do interstitial (1 a cada 5) | sheet leve → paywall | — |
| `home_card` | card na Home | paywall | — |
| `settings` | "Conheça o PRO" | paywall | — |

### 4.3 Permissões

| Recurso | Android 13+ | Android ≤ 12 | Se negado |
|---|---|---|---|

Pedidos só no momento do uso; nunca na abertura do app.

### 4.4 Offline

Tudo funciona sem internet: criar, exportar, salvar, compartilhar. Não funciona: compra (mensagem no paywall), anúncios (pulados), preço no card da Home (omitido). O status PRO é lido do cache local; a revalidação com a Play acontece quando houver rede.

## 5. Microinterações e feedback

- **Cards:** pressionar → escala 0,97 + haptic leve. Preview dos cards com fade-in ao decodificar a foto.
- **Editor:** canvas atualiza ao vivo a cada tecla; sugestão tocada aplica com um "pulso" no texto; 🎲 gira 180°.
- **Gerar:** botão vira barra de progresso indeterminada ("Gerando…"); ao terminar, haptic de sucesso e o meme "sobe" para a tela de resultado (transição compartilhada).
- **Compartilhar:** haptic leve; sem animação (a share sheet do sistema é a resposta).
- **Salvar:** toast curto + botão vira "Salvo ✓".
- **Compra:** toast "Bem-vindo ao PRO 🎉"; a pill do header troca para "✓ PRO" com um pequeno brilho. Sem confete (custo/benefício).
- **Movimento reduzido** (configuração do sistema): desliga escalas e transições, mantém fades.

## 6. Acessibilidade e Android

- Alvos de toque ≥ 48dp; contraste AA na interface (o conteúdo do meme é escolha do usuário).
- Escala de fonte do sistema respeitada na interface; **ignorada no canvas** (o meme precisa renderizar igual em qualquer aparelho).
- Botões só-ícone com rótulo para leitor de tela; a sheet de texto anuncia o slot que está editando.
- Teclado: a sheet de texto sobe com o teclado; o canvas continua visível acima (é o feedback ao vivo).
- Orientação: retrato apenas.
- Aparelhos pequenos (≤ 5,5", 720p): Home cabe sem rolagem até "Populares"; editor mostra canvas + 2 slots + CTA sem rolagem.
