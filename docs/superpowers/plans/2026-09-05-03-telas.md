# Print Vira Meme — Plano 1b-2: Telas do MVP — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`).

**Goal:** Fechar o fluxo completo do produto no aparelho: Home → foto → template → editor → gerar → resultado → compartilhar, com paywall, configurações e entrada pelo "Compartilhar" do Android.

**Architecture:** As telas são finas: leem stores (creation/entitlements/counters), chamam hooks (`useExport`, `usePaywall`, `useAdGate`, `usePhotoFlow`) e renderizam componentes. Todo desenho de meme passa pelo `MemeCanvas` já pronto — cards, editor e exportação usam o mesmo componente, só muda a escala. Sheets (foto, texto, PRO leve) são um wrapper próprio `Sheet` sobre `@gorhom/bottom-sheet` que só monta os filhos quando aberto (assim o mock do Jest reflete o estado real).

**Tech Stack:** Expo Router, @gorhom/bottom-sheet 5, Reanimated 4 + Gesture Handler 2.32, expo-image, RNTL 14 (async).

**Spec:** [02-ux.md](../../02-ux.md) §3–4 · [03-ui.md](../../03-ui.md) §2–3 · plano anterior [2026-09-05-02-nucleo-1.md](2026-09-05-02-nucleo-1.md)

## Global Constraints

- Textos sempre de `src/i18n/strings.ts`; cores/medidas de `src/theme/tokens.ts`.
- Nenhuma tela chama serviço nativo direto: só via `services` + hooks.
- RNTL 14: `await render`, `await fireEvent`, `await renderHook`.
- Free entra no editor com preset PRO; o bloqueio acontece só em "Gerar" (UX §3.3/3.4).
- AdGate **apenas** em "Criar outro meme" e ao voltar do Resultado para a Home.
- Cada task termina com `npm run typecheck && npm test` verdes + commit em `feat/telas`.

### Task 1: `Sheet`, `TemplateCard` e blocos da Home

**Files:** `src/components/ui/Sheet.tsx`, `src/components/TemplateCard.tsx`, `src/components/home/*.tsx`, testes `src/components/__tests__/TemplateCard.test.tsx`, `Sheet.test.tsx`
**Interfaces:**
```ts
<Sheet open onClose snapPoints? children />               // gorhom; filhos só quando open
<TemplateCard preset image? width onPress locked? isNew? />  // scale = min(w/1080, h/canvasH)
<HeroButton onPress />  <SectionHeader title onSeeAll? />  <ProCard onPress />  <PresetCarousel presets image? onSelect />
```
**Testes:** card mostra nome, badge PRO quando bloqueado, badge NOVO; usa a foto do usuário quando há (senão a foto-exemplo); Sheet não renderiza filhos fechado e renderiza aberto.
**Verificação:** `npx jest src/components` · commit `feat(ui): Sheet, TemplateCard com preview ao vivo e blocos da Home`.

### Task 2: Home + `usePhotoFlow` + `PhotoSheet`

**Files:** `src/app/index.tsx`, `src/components/PhotoSheet.tsx`, `src/hooks/usePhotoFlow.ts`, testes `src/app/__tests__/home.test.tsx`
**Interfaces:**
```ts
usePhotoFlow() → { pick(source: 'gallery'|'camera'): Promise<boolean>, picking: boolean, error: string | null, clearError(): void }
```
`pick` importa a foto (services.image.pick), grava no creationStore, emite `image_selected` e devolve `true` no sucesso.
**Testes:** Home mostra herói, 8 chips, populares e novidades; card PRO só para Free; toque no herói abre a sheet; escolher galeria fecha a sheet e navega para `/templates`; permissão negada mostra a mensagem inline.
**Verificação:** `npx jest src/app` · commit `feat(home): tela inicial com herói, categorias, carrosséis e sheet de foto`.

### Task 3: Catálogo (`/templates`)

**Files:** `src/app/templates.tsx`, teste `src/app/__tests__/templates.test.tsx`
**Comportamento:** chips (Todos/🔥/✨/8 categorias, com a categoria da URL pré-selecionada), grade 2 colunas com preview ao vivo, miniatura da foto no header (toque troca a foto), card → `setPreset` + `/editor` (sem foto: abre a sheet e segue para o editor depois).
**Testes:** filtra por categoria; sem foto usa a foto-exemplo; toque no card com foto navega para `/editor` e grava o preset; `preset_selected` emitido.
**Verificação:** `npx jest src/app/__tests__/templates.test.tsx` · commit `feat(templates): catálogo com filtros e preview ao vivo`.

### Task 4: Editor — canvas, slots, fontes e estilo

**Files:** `src/app/editor.tsx`, `src/components/editor/CanvasFrame.tsx`, `SlotField.tsx`, `FontChip.tsx`, `StyleControls.tsx`
**Comportamento:** header com nome do preset e badge PRO; canvas limitado a 55% da altura útil; lista de slots; fontes (PRO com cadeado → paywall `premium_font`); CAPS livre, cor/contorno PRO; CTA fixo "Gerar meme" ou "Desbloquear PRO e gerar" (paywall `premium_template` com continuação = exportar).
**Testes:** preset PRO + Free mostra o CTA de desbloqueio e abre o paywall; Free em preset free exporta e vai para `/result`; fonte PRO abre paywall; CAPS aplica.
**Verificação:** `npx jest src/app/__tests__/editor.test.tsx` · commit `feat(editor): canvas, slots, fontes e estilo com regras Free/PRO`.

### Task 5: `TextSheet` e gestos na foto

**Files:** `src/components/editor/TextSheet.tsx`, `ImageGestureLayer.tsx`
**Comportamento:** sheet com campo, contador, sugestões (catálogo, filtradas por tipo/maxChars/categoria) e 🎲; canvas atualiza ao vivo. Gestos: pinça/arraste no slot da imagem com `clampTransform` no fim; toque duplo reseta; botão Preencher/Encaixar.
**Testes:** sugestão aplica o texto e emite `suggestion_used`; digitar respeita `maxChars`; alternar fit muda `imageTransform.fit`.
**Verificação:** `npx jest src/components/editor` · commit `feat(editor): sheet de texto com sugestões e gestos de enquadramento`.

### Task 6: Resultado + `useShareFlow` + `ProLiteSheet`

**Files:** `src/app/result.tsx`, `src/hooks/useShareFlow.ts`, `src/components/ProLiteSheet.tsx`
**Comportamento:** mostra o arquivo exportado; Compartilhar (conta `meme_shared`, marco do 3º compartilhamento); Salvar (galeria + toast, trata negado); "Outro template" volta ao catálogo com a mesma foto (sem anúncio); "Criar outro meme" passa pelo AdGate e limpa a criação; Free vê "Tirar a marca d'água · PRO" (continuação = re-exportar sem marca); PRO vê "HD ✓".
**Testes:** compartilhar emite evento e incrementa contador; 3º compartilhamento abre a sheet PRO leve uma única vez; salvar negado mostra a mensagem; "Criar outro" chama o AdGate.
**Verificação:** `npx jest src/app/__tests__/result.test.tsx` · commit `feat(result): compartilhar, salvar, outro template e AdGate`.

### Task 7: Paywall `/pro` e Configurações

**Files:** `src/app/pro.tsx`, `src/app/settings.tsx`
**Comportamento paywall:** frase do gatilho, checklist (5 itens), preço da loja (skeleton enquanto carrega), compra → grava entitlements, toast, executa a continuação e fecha; restaurar; offline/erro/cancelado com as mensagens do `strings`.
**Configurações:** status PRO, restaurar, compartilhar o app, avaliar, privacidade (texto + link), opt-out de analytics, limpar cache, versão.
**Testes:** contexto por gatilho; compra executa a continuação e fecha; restore sem compra mostra a mensagem; opt-out desliga o analytics.
**Verificação:** `npx jest src/app/__tests__/pro.test.tsx src/app/__tests__/settings.test.tsx` · commit `feat(pro+settings): paywall com continuação e configurações`.

### Task 8: Entrada por "Compartilhar" e limpeza de cache

**Files:** `src/hooks/useIncomingImage.ts`, `src/app/_layout.tsx`
**Comportamento:** `useIncomingShare` do expo-sharing; payload de imagem → importa, grava e `router.replace('/templates')`, emite `app_open(entry=share_intent)`; não-imagem → toast; limpeza de cache (24 h) na abertura.
**Testes:** payload de imagem navega para `/templates` com a foto; texto mostra o toast e não navega.
**Verificação:** `npx jest src/hooks/__tests__/useIncomingImage.test.tsx` · commit `feat(share-intent): receber imagem de outros apps e limpar cache na abertura`.
